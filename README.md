# ForgeFit

Offline-first Android fitness tracker built with Java.

## Features

- Workout management
- Exercise tracking
- Session history
- Statistics
- Offline persistence

## Tech Stack

- Java
- Android SDK
- Room Database
- MVVM
- Material Design
